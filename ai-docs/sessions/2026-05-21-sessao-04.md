# Sessão 04: Modernização Visual e Experiência do Usuário (UI/UX)

Nesta sessão, focamos em elevar a qualidade estética da Navbar para um padrão "Premium", utilizando tendências modernas de design.

## O que foi discutido e decidido:

1.  **Design Floating Glass:**
    *   Decidimos abandonar o visual padrão do Angular Material por uma barra flutuante com efeito de vidro (Glassmorphism).
    *   Utilizamos transparência controlada e desfoque de fundo (`backdrop-filter`) para profundidade.

2.  **Evolução dos Dropdowns:**
    *   Substituímos os menus `<select>` nativos (datados) por componentes personalizados que abrem ao passar o mouse (hover).
    *   Ajustamos a translucidez para 80% para um equilíbrio entre estética e legibilidade.

3.  **Micro-interações Reativas:**
    *   Implementamos um placeholder animado (efeito typewriter) na barra de busca para tornar a interface "viva".
    *   Refinamos o item de Perfil para agrupar Login e Cadastro de forma elegante, mantendo o alinhamento original de ícone/texto.

4.  **Desafios Técnicos Superados:**
    *   Correção de erros de build após a migração para Signals (sincronização TS/HTML).
    *   Resolução de conflitos de empilhamento (`z-index`) entre as duas barras da Navbar.
    *   Ajuste de bordas fixas na busca para garantir estrutura visual constante.
