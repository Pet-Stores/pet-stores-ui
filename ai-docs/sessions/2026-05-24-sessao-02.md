# Sessão - 2026-05-24-sessao-02

## Resumo Executivo
Nesta sessão, implementamos o sistema de autenticação e o modal de login para a plataforma Pet Stores. O foco foi em criar uma experiência de usuário (UX) premium, com componentes inteligentes e segurança reforçada seguindo as melhores práticas do mercado.

## Pontos Principais e Decisões
1.  **Modal de Login Premium**: Criamos um modal moderno com efeito de desfoque de fundo (Backdrop Blur), bordas arredondadas e feedback visual suave.
2.  **Smart Input (Internacional)**: Implementamos um campo único para e-mail ou telefone que detecta automaticamente o tipo de entrada. Se for telefone, o sistema identifica o país pelo DDI, troca a bandeira dinamicamente e aplica a máscara correspondente (Brasil, EUA, Portugal, etc.).
3.  **Segurança (Prevenção de Enumeração)**: Por sugestão de segurança, adotamos mensagens de erro genéricas ("E-mail, telefone ou senha incorretos") para evitar que atacantes descubram e-mails cadastrados na base.
4.  **Mock de Autenticação**: Criamos um `AuthService` com usuários mockados para testes imediatos, integrando a persistência de sessão via `localStorage`.
5.  **UI Reativa**: A Navbar agora reflete o estado do usuário logado, exibindo seu primeiro nome e uma foto de perfil ampliada com efeitos de hover.

## Desafios Resolvidos
*   **Problema de Deleção na Máscara**: Ajustamos a lógica de máscara para não ser agressiva, permitindo que o usuário apague o prefixo do país caractere por caractere sem travas.
*   **Renderização de Imagem**: Corrigimos o caminho dos assets para garantir que a foto de perfil carregue corretamente em todas as rotas do Angular.
*   **Reset de Campo**: Implementamos o reset automático do modo "telefone" para o modo "indefinido" quando o campo é limpo.
